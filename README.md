# GhostWrite 👻

A local AI-powered ghost story generator built for the Hacktoberfest 2026 Open-Source AI Challenge.

## Features

- Generate short ghost stories from user-provided prompts
- Runs locally using an open-weight language model
- Simple Streamlit interface
- No external AI API key required

## Tech Stack

- Python
- Streamlit
- Hugging Face Transformers
- TinyLlama 1.1B Chat

## Installation

\`\`\`bash
git clone https://github.com/YOUR_USERNAME/ghostwrite.git
cd ghostwrite

python -m venv .venv
.\.venv\Scripts\activate

pip install -r requirements.txt
streamlit run app.py
\`\`\`
